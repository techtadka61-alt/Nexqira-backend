# Future Features

## Main Features
1. Admin dashboard for approval of all posts before posting to website and LinkedIn.
2. Option to choose whether to post blog to LinkedIn, website, or both.
3. Admin receives email for verification and can review/approve posts directly from Gmail.
4. Unsplash integration for images.

## Security Features (Planned)
- Admin authentication and role-based access control (RBAC)
- Rate limiting for API endpoints
- Input validation and sanitization to prevent XSS/SQLi/NoSQLi
- CSRF protection for admin actions
- Secure API keys and secrets management
- Audit logging for admin and critical actions
- Email verification for admin actions
- Protection against brute-force and automated attacks
